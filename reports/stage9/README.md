# Этап 9: проверка на известных составах (WHAT-IF)

> **Это не реальные проценты побед.** Ни одного числа из RU-клиента получить не удалось: lunafantasy.ru,
> appmedia.jp, qoo-app.com и surrounded-by-girls.online заблокированы сетевой политикой облачной сессии.
> Поэтому:
> * навыки всех героинь — **общие ролевые шаблоны** (`luna/scenarios.py`), выбранные по косвенным данным
>   (JP-сниппеты AppMedia/Dengeki с достоверностью LOW, ваше утверждение «Верафиэль — поддержка»);
> * все характеристики — UNKNOWN и сэмплируются из **одинаковых для всех** широких априоров
>   (`data/scenarios/priors_symmetric_v1.json`; масштаб привязан к JP-сэмплу Вигнетты с AppMedia);
> * величины гипотез (+20% пробития и т.п.) — входные what-if значения, а не игровые эффекты;
> * составы A и B — тестовые составы из задания, **не ваш подтверждённый ростер**.
>
> * русские написания имён в этом отчёте (Химель, Кира, Сенерен, Вигнетта, Хлоя, Серафия, Никсара…) — моя
>   транслитерация, **не подтверждённые названия RU-клиента**; подтверждено только «Верафиэль» (и прозвище «Монашка»).
>
> Значит, выводы касаются **структуры** (роли, механики, порядок триггеров), а не реального баланса.

## Воспроизведение

```bash
luna scenario hypotheses -n 400 --workers 4 --out reports/stage9/hypotheses.json
luna scenario scenario3 --workers 4 --out reports/stage9/scenario3.json
luna matchup data/scenarios/team_A.json data/scenarios/team_B.json --catalog data/scenarios/catalog_whatif_RU.json \
  --priors data/scenarios/priors_symmetric_v1.json --set 'battle.draw_result="hp_percent"' --key vignette seneren \
  -n 300 --suggest --seed 3 --out reports/stage9/matchup_A_vs_B.json
```

Сид 2026, по 400 боёв на прогон, парное сравнение на общих случайных числах (common random numbers, CRN).
Для каждой гипотезы — 4 варианта допущений × 2 направления:
`exploratory_v1` / `exploratory_v1_alt` (тайминг доп. действий, лимит цепочки комбо, стакание дублей)
× `death.trigger_order` = kill_effects_first / death_effects_first.
Вывод считается устойчивым, только если знак эффекта значим во **всех** вариантах.

## Базовая линия: команда A против команды B

Модельный WR команды A = **0.718** [0.671; 0.759] во всех четырёх вариантах. Варианты совпадают, потому что
в базовых составах нет ни комбо, ни эффектов при убийстве. 92% боёв доходят до лимита в 15 раундов, и исход
решает допущение `battle.draw_result=hp_percent` (реальное правило UNKNOWN). Это главное ограничение всех чисел ниже.

## Анализ матчапа A против B (`matchup_A_vs_B.*`)

* Модельный WR 0.69 [0.64; 0.74], 286 из 300 боёв дошли до лимита раундов.
* Ключевые героини A: Вигнетта (6.86 воскрешений за бой), Люцифер (26% урона), Кира (25%).
  Ключевые у B: Сенерен (самовоскрешение), Люцифер (43% урона B; главный источник — `lucifer_burst`, 31% урона).
* Вероятность смерти ключевых саппортов A: Вигнетта 0.3%, Сенерен 22%.
* Причины поражений: первой всегда погибает Химель (первый ряд, позиция 0); главные убийцы — Хлоя и Люцифер.
* Лучшие изменения (парное сравнение на общих случайных числах): Сенерен ↔ Люцифер или Химель, то есть Сенерен
  в первый ряд, даёт ΔWR **+0.18** [0.14; 0.23]. Причина по метрикам: самовоскрешение Сенерен тратится
  на танкование, урон команды растёт на 9%.

## Сценарий 3: Серафия (Монашка), Никсара, Сенерен + 3 неизвестных

Перебраны 24 случайных набора из трёх героинь из пула названных (`scenario3.*`). Модельный WR против A/B:
мин 0.15, медиана 0.58, макс 0.92. Лучшие наборы содержат Вигнетту и Верафиэль: в этой модели выигрывает
устойчивость к урону (sustain), что опять же следствие правила HP% на лимите раундов.

## Оптимизатор (режим Anti-Meta, GA + ранжирование по Парето)

`optimizer_anti_meta.*`: GA за 6 поколений (69 оценок, 6800 боёв) нашёл
`illusia, vignette, verafiel, hymelle, lucifer, seneren` с модельным WR 0.985 против A и B.
**Проверка на чувствительность (`compare_*`):** при `battle.draw_result=hp_percent` состав лучше A на +0.30
[0.245; 0.355]. При `battle.draw_result=draw` разница −0.01 [−0.039; +0.019], то есть незначима.
Оптимизатор нашёл эксплойт допущения о ничьей, а не сильную команду. Пример того, почему модельный WR нельзя
считать реальным, пока правило окончания боя и навыки не подтверждены.

## Что нужно, чтобы эти выводы стали реальными

1. Тексты и числа навыков героинь из RU-клиента или lunafantasy.ru (`luna collect --offline-dir`, `luna kb import-csv`).
2. Правило окончания боя по лимиту раундов и сам лимит.
3. Порядок срабатывания эффектов при смерти (критично для H5).
4. 20 и более реальных боёв с полными составами для калибровки (`luna validate import/calibrate`).
